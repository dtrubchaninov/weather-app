## 📌 О проекте

**WeatherCast** — это распределённый программный комплекс, реализующий архитектуру **«Клиент-Сервер» (Client-Server)** для удалённого мониторинга и управления погодным инфо-экран в локальной сети по протоколу **TCP/IP**.

Система состоит из двух независимых графических приложений:
1. 🖥️ **Серверный экран (`server.py`)** — информационный дашборд погоды с прогнозом на 5 дней, метеопараметрами и встроенным многопоточным TCP-сервером.
2. 🎮 **Клиентский пульт (`client.py`)** — графический пульт ДУ для управления экраном с другого компьютера, ноутбука или планшета в реальном времени.


### 🖥️ Сервер (`server.py`)
- **Автоопределение IP:** При старте программа автоматически определяет свой локальный IP-адрес в Wi-Fi сети и отображает его в шапке окна (`IP для пульта: 192.168.x.x:8888`).
- **Многопоточный сокет-сервер:** Слушает порт `8888` в отдельном потоке daemon-thread, не блокируя графический интерфейс.
- **Живой сетевой лог:** В шапке отображается IP подключившегося пульта и имя выполненной команды.
- **Полноценная метеорология:** Температура, влажность, скорость и стороны света ветра, атмосферное давление в мм рт. ст., УФ-индекс и прогноз на 5 дней.

### 🎮 Клиентский пульт (`client.py`)
- **Управление городами:** Быстрая сетка из 8 городов в один клик + поле ввода любого произвольного города мира.
- **Дистанционные переключатели:** Мгновенное переключение шкалы (°C / °F) на экране.
- **Пейджер сообщений:** Возможность отправить текстовое оповещение на экран сервера.
- **Окно телеметрии:** Лог подтверждений и отчётов с сервера с точными временными метками.


## 📁 Структура проекта

```text
.
├── server.py        # Устройство 1: Точка входа сервера и погодного экрана
├── client.py        # Устройство 2: Графический интерфейс пульта
├── network.py       # Сетевое ядро: классы WeatherServer и WeatherClient
├── ui.py            # Графический интерфейс экрана: отрисовка погоды и приём 
├── api.py           # Сетевой клиент Open-Meteo REST API (IPv4-forced,таймауты)
├── constants.py     # Цветовая палитра Slate, коды WMO, список городов
├── utils.py         # Математика сторон света и форматирование градусов
└── README.md        # Документация проекта
```

## 🚀 Инструкция по запуску

### Вариант А: Тестирование на одном компьютере (Локально)

1. **Терминал 1 (Сервер-экран):**
   ```bash
   python3 server.py
   ```

2. **Терминал 2 (Графический пульт):**
   ```bash
   python3 client.py
   ```
   *Откроется окно пульта. Нажмите кнопку **Подключиться** (по умолчанию `127.0.0.1:8888`) и управляйте экраном с помощью пульта*

---

### Вариант Б: Запуск на двух разных устройствах (ПК ↔ Ноутбук)

> 📶 **Требование:** Оба устройства должны быть в одной локальной сети.

1. **На первом компьютере (Сервер):**
   - Запустите:
     ```bash
     python3 server.py
     ```
   - Запомните IP-адрес из синей плашки вверху окна (например: `192.168.1.105`).

2. **На втором компьютере (Пульт):**
   - Скопируйте файлы `client.py`, `client_gui.py` и `network.py`.
   - Запустите:
     ```bash
     python3 client.py
     ```
   - В поле **IP адрес** введите IP первого компьютера (`192.168.1.105`) и нажмите **«Подключиться»**.


## 🛠️ Сборка автономных бинарных файлов (PyInstaller)

```bash
# Установка компилятора
pip install pyinstaller

# Сборка сервера в один файл:
pyinstaller --onefile --noconsole --name "WeatherServer" server.py

# Сборка пульта в один файл:
pyinstaller --onefile --noconsole --name "WeatherRemote" client.py
```
Готовые бинарники будут лежать в каталоге `dist/`.
