# 🌤️ Приложение прогноза погоды

Автономное нативное приложение для просмотра текущей погоды и прогноза на ближайщие 5 дней с подробными метеорологическими параметрами.

Интерфейс приложения построен на стандартной библиотеке **Tkinter**, а данные берутся из бесплатного REST API **Open-Meteo**.

---

## ✨ Возможности

- 🔍 **Поиск по любому городу мира** (геокодинг Open-Meteo Geocoding API на русском языке).
- ⚡ **Быстрый выбор популярных городов** (Москва, Санкт-Петербург, Казань, Сочи, Новосибирск, Владивосток, Минск, Алматы).
- 🌡️ **Переключение единиц измерения** (°C / °F).
- 📊 **Текущие погодные условия:**
  - Фактическая температура и показатель «Ощущается как».
  - Погодный код WMO с описанием на русском и иконкой.
  - Влажность воздуха (%).
  - Скорость ветра (км/ч) и направление по сторонам света (С, ЮВ, З и т.д.).
  - Атмосферное давление в мм рт. ст.
  - УФ-индекс (максимальный за день).
- 📅 **Прогноз на 5 дней** с распределением минимальных и максимальных температур.
- 🚀 **Асинхронные запросы** — интерфейс не зависает во время загрузки данных из сети.

## 📁 Структура проекта

```text
.
├── main.py          # Точка входа, настройка DPI Windows и запуск GUI
├── ui.py            # Класс DesktopWeatherApp: вёрстка и отрисовка интерфейса Tkinter
├── api.py           # Запросы к Open-Meteo
├── constants.py     # Цветовая палитра Slate, коды WMO, список городов, дни недели
└── utils.py         # Вспомогательные функции (расчёт сторон света, формат температуры)
```


### 🐧 Linux

В некоторых дистрибутивах Linux модуль `tkinter` вынесен в отдельный системный пакет:

```bash
# Ubuntu / Debian / Mint:
sudo apt update && sudo apt install -y python3-tk

# Fedora / RHEL:
sudo dnf install -y python3-tkinter

# Arch:
sudo pacman -S tk
```

Запуск:
```bash
python3 main.py
```

### Windows / macOS

Запуск:
```cmd
python main.py
```

## 📦 Сборка в один автономный бинарный файл

Приложение можно скомпилировать в исполняемый файл с помощью **PyInstaller**.

### 1. Установите PyInstaller
```bash
pip install pyinstaller
```

### 2. Запустите сборку

**Для Linux**
```bash
pyinstaller --onefile --noconsole --name "WeatherApp" main.py
```

**Для Windows**
```powershell
pyinstaller --onefile --noconsole --name "WeatherApp" main.py
```

*(Если у вас есть файл иконки, добавьте флаг `--icon=app.ico`)*.

### 3. Где найти готовый файл:

После сборки готовый файл появится в каталоге:
- **Linux:** `./dist/WeatherApp`
- **Windows:** `dist\WeatherApp.exe`
